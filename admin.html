Songs and frames are saved to the GitHub repo that hosts this site. GitHub then scans them (chorus + photo windows) and updates the app automatically.

How do I get a token?
  1. Open GitHub → Fine-grained token.
  2. Expiration: a date after the wedding.
  3. Repository access: Only select repositories → your WeddingSnap repo.
  4. Permissions: Contents → Read and write, Actions → Read-only.
  5. Generate, copy and paste it above. Keep it secret - it's like a password.
